# Artist Website

## Description:

Artist Website is a web application for showing my artwork, including paintings, drawings, sculptures, and work in other media.  It includes images as well as an artist statement, biography, and CV of my exhibition history.  The application is written in JavaScript and uses Express and Node.js for the back end, React for the front end, and SQLite for the database.
