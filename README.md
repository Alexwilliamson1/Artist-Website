# Artist Website

## Description:

Artist Website is a web application for showing my artwork, including paintings, drawings, sculptures, and work in other media.  It includes images as well as an artist statement, biography, and CV of my exhibition history.  The application is written in JavaScript and uses Express and Node.js for the back end, React and Vite for the front end, and SQLite for the database.  It is currently deployed by Railway at artist-website-production.up.railway.app.

## Instructions:

To run the program locally, open a command-line interface at both the “client” and “server” directories and run `npm install` in each to install the software dependencies.  Use the commands `npm run dev` and `node server.js` to run the client and server, respectively, and in the address bar of a browser, type `http://localhost:5173/`.  

## Requirements:

To run the program locally, one requires Node.js 22 or later, Node package manager (npm), and a modern web browser.  Node.js and npm can be installed together from https://nodejs.org/en.

## Notes:
The size of the program is large for downloading due to the number of image files.  The program was also tested on macOS 15.7 using Clang.
